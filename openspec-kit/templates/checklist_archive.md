# Archive総括レビューチェックリスト（Gate 3 / Definition of Done）

対象: 変更全体の成果物（実装・テスト・仕様・ドキュメント・レビュー記録・フェーズゲート検証結果）

レビュアー: 全役割（User / SE / PG / QA Reviewer Agent）

## デルタ仕様のメイン仕様への反映・タスク完了

| #   | 観点                                                                      | 判定     | コメント |
| --- | ------------------------------------------------------------------------- | -------- | -------- |
| 1   | デルタ仕様が `openspec/specs/` に正しく反映される（または反映済み）状態か | ✅/❌/⚠️ |          |
| 2   | メイン仕様の整合性（矛盾・重複・抜け）がないか                            | ✅/❌/⚠️ |          |
| 3   | 仕様変更の履歴・理由が追跡可能か                                          | ✅/❌/⚠️ |          |
| 4   | `tasks.md` の全タスクが `[x]` で、未完了・先送りのタスクが 0 件か         | ✅/❌/⚠️ |          |

| #   | 観点                                                                                                 | 判定     | コメント |

| 6   | カバレッジ基準（C0: 80%+/差分90%+、C1: 80%+/差分85%+、C2: 対象100%、Scenario: 100%）を達成しているか | ✅/❌/⚠️ |          |
| 7   | テスト実行結果のエビデンス（テストレポート、カバレッジ、画面キャプチャ）が確認・記録されているか     | ✅/❌/⚠️ |          |
| 8   | ビルドエラー 0 件・新規警告 0 件・静的解析/リンターエラー 0 件・フォーマッタ差分 0 件か              | ✅/❌/⚠️ |          |
| 9   | プロダクションコードに未解決の `TODO` / `FIXME` / `HACK` やデバッグ出力が残っていないか              | ✅/❌/⚠️ |          |
