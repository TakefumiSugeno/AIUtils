# 自動フォーマット定義

採用技術スタック決定後、本ドキュメントに使用するリンター・フォーマッタおよびコマンドを具体化する。原則として以下の種別ごとにプロジェクト標準ツールを設定・適用すること。

| 対象種別 | 適用タイミング | 整形方針・標準ツールの選定基準 |
| :--- | :--- | :--- |
| **ソースコード** | ファイル更新時 / コミット前 / テスト実行前 | 採用言語・フレームワークの公式推奨フォーマッタ（例: `Prettier`, `dotnet format`, `rustfmt`, `gofmt`, `black` 等） |
| **テストコード** | ファイル更新時 / コミット前 / テスト実行前 | ソースコードと同一のフォーマットルールを適用 |
| **ドキュメント (`.md`)** | ドキュメント更新時 / コミット前 | Markdown 標準フォーマッタ（例: `Prettier` 等）によるインデント・改行・表組みの統一 |
| **UIモック / Web資産** | モック・UI更新時 / コミット前 | HTML / CSS / JS / JSON 等の標準ウェブフォーマッタによる整形 |
| **設定・スクリプト** | 更新時 / コミット前 | JSON, YAML, 各種シェルスクリプト用静的解析・整形ツール |
