## 1. カバレッジ目標と完了基準

| 指標                          | 定義                                                                  | 目標値（全体 / 新規・変更差分） | 適用対象・備考                                  |
| :---------------------------- | :-------------------------------------------------------------------- | :------------------------------ | :---------------------------------------------- |
| **C0 (命令網羅 / Line)**      | 実行可能な全ステートメントの網羅率                                    | **80%以上** / **90%以上**       | `verify-gate.ps1` / `verify-gate.sh`            |
| **C1 (分岐網羅 / Branch)**    | `if/else`, `switch/match`, ガード節, 例外経路の真偽両方の網羅率       | **80%以上** / **85%以上**       | `verify-gate.ps1` / `verify-gate.sh`            |
| **C2 (条件網羅 / Condition)** | 複合条件式（`A && B \|\| C`）の各基本条件の真偽組み合わせ網羅         | **100%**（対象ロジック）        | ゲート判定ロジック（`Assert-ReviewsValid` 等）  |
| **Scenario 網羅率**           | `specs/**/spec.md` の全 `#### Scenario:` に対する結合/E2Eテスト対応率 | **100%**                        | 下記「2. トレーサビリティマトリクス」で対応付け |

- **カバレッジ除外対象**: 静的Markdownテンプレートファイル（レビューチェックリスト、エージェントプロンプト）
- **モック境界方針**:
  - **モック化する外部境界**: Gitコマンド実行（テスト環境でのみ `-SkipGitCheck` 使用）
  - **実物を使用する範囲**: 実ファイルシステム上の `reviews.md`、テンプレートファイル、スクリプト実行
